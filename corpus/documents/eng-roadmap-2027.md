The 2027 roadmap has three themes.

First, route optimisation for outbound shipments, under the codename Project Kestrel. It will
suggest carrier and loading order for each truck. A first version is planned for the Pro tier
in the third quarter.

Second, a new event pipeline so customers can receive stock changes in real time instead of
polling the API.

Third, reliability: certificate automation, faster restores and a second region for the
database.
