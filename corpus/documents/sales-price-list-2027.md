The 2027 prices apply to new contracts signed from 1 January 2027.

Starter, plan code STR-27-S1: 690 EUR per site per month. Pro, plan code PRO-27-S2: 1,890 EUR
per site per month, with a minimum of two sites. Enterprise, plan code ENT-27-Q: quoted per
customer, starting at 4,500 EUR per month.

Implementation services are billed at 950 EUR per day. Existing customers keep their current
prices until renewal.
